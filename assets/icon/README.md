# App icon (placeholder)

The launcher icon is a simple indigo rounded square with "LR". It lives in
`android/app/src/main/res/mipmap-*/ic_launcher.png` (48/72/96/144/192 px).

To swap it: replace those five PNGs with your own (same file names), or use
[flutter_launcher_icons](https://pub.dev/packages/flutter_launcher_icons)
with `image_path` pointing at your artwork and re-run it.
